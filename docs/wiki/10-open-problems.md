# Open problems and working hypotheses

The system collects and describes observations. It has manual case grouping,
several ways to send a notice, and limited evidence of what happens after
delivery. The open question is whether a credible public record and a suitable
direct route improve the condition faster, including cases where the party
repairs it quietly. [Notice and remediation](12-notice-and-remediation.md)

Everything on this page is `[inference]` unless it cites another page. It is
here to be argued with.

## B. Working hypotheses

Each one says what would show it to be wrong.

**H1. Publication can add value to direct notice.** An evidence-backed public
record may improve decision-owner reach or verified remediation when a
relevant audience can use it. Compare suitable direct notice on comparable
low-risk issues with and without eligible public posting. A low private reply
rate describes that channel. The comparison needs similar evidence quality
and follow-up coverage.

**H2. The issue is a useful unit of action.** Test grouping on repeat imports,
probable matches, independent corroboration, and near-neighbor mismatches.
Compare reviewers' agreement by class and measure false merges. Keep the
source observations available when an issue groups several records.

**H3. Fewer and better.** A hundred issues with clean evidence do more than a
million records.
Compare packets with similar issues, routes, and coverage. Track correction,
duplicate burden, decision-owner reach, and which evidence recipients use.

**H4. Facts before dollars.** The number of distinct sources, how long the
issue has existed, and any observed recurrence can support decisions where
sources and scope are comparable. Show where those facts are sufficient for
a decision and where a defensible estimate of harm or cost changes it.

**H5. Relevant interested parties can improve outcomes.** An actor with
oversight, authority, or a legitimate stake can use a credible record in a
real decision. Evidence of readership measures reach. Evidence that the
record informed a decision tests usefulness. Buyer demand is a separate
hypothesis.

**H6. A low-friction response can make cooperation worthwhile.** Accept a
redirect, dispute, or repair reference in an existing workflow. Test whether
the offer of private handling and appropriate public credit improves useful
dispositions. Track publication permission and supporting evidence separately.
Compare verified remediation too, since participation can move in a different
direction.

**H7. Independent rechecks can reveal remediation among silent recipients.**
Decide how to recheck the underlying condition before enrollment. Track the
change and its scope, the owner response if available, and evidence of
attribution separately. Report cases that remain unverifiable and the cost
to verify those that can be checked.

## D. A first test after strategy review

Keep new case studies and outreach deferred during strategy review. The
already published Google Ads case is a retrospective example of differing
receipt and response evidence. Several simultaneous changes to that case
would leave their individual effects unclear.

Once a pilot has a question and a budget, reuse case drafts, selected targets,
and manual outcome notes for a bounded, approved test. Start with issues
where a human can confirm the observation, identify an appropriate route,
and repeat the underlying check. Keep a dated evidence record, including
which cases yielded no route, reply, or affordable recheck. The first test
asks whether this workflow can produce reliable observations. A later
comparison asks which routing or publication choice improves outcomes.
